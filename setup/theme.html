Syndicates Client

Reskin Chrome's top bar & footer

Chrome only lets a theme recolour the tab strip, address bar, bookmarks bar and the new-tab footer. Extensions can't do it themselves, so Syndicates Client ships matching themes. It takes 30 seconds.

Pick a look

Install it

  1. Open the Extensions page.
  2. Make sure Developer mode (top-right switch) is on.
  3. Click Load unpacked.
  4. Go into the same yiling folder you loaded Syndicates Client from, open themes, select the folder of the look you picked (e.g. cyber-red) and click Select Folder.
    Pick the theme folder itself, not yiling or themes.
  5. Chrome switches immediately: tabs, address bar and bookmarks bar turn cyber, and the footer picks up the theme colours. It shows up as a theme, not in your extension list.

Hide Chrome's footer completely

Chrome adds this bar to every extension's new tab page, so it can only be switched off in Chrome itself. Use whichever works for you:

  1. Right-click directly on the bottom bar → Hide footer (newer Chrome versions).
  2. Policy file (recommended): double-click tools\windows\hide-new-tab-footer.reg → Yes, then close every Chrome window and reopen. Check chrome://policy – NTPFooterExtensionAttributionEnabled should show false · OK. Chrome will say "Managed by your organization" – normal. Undo: show-new-tab-footer.reg.
  3. Startup switch: double-click tools\windows\start-chrome-without-footer.bat, or make it permanent: right-click your Chrome shortcut → Properties → at the end of Target add --disable-features=NtpFooter.

Go back to normal

Chrome Settings → Appearance → Theme → Reset to default.

Want your own colours? Edit tools/make-themes.py in the yiling folder and run python3 tools/make-themes.py, then load the new folder the same way.
